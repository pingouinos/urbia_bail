Modèles des documents

Modifier un modèle dans Google Docs

  1. La première fois : télécharger le modèle en service (Word), l'importer dans Google Drive, puis Ouvrir avec > Google Docs. Dans Partager > Accès général, choisir « Tous les utilisateurs qui ont le lien », rôle Lecteur, puis copier le lien et le coller ci-dessous.
  2. Modifier le texte dans Google Docs, en laissant intactes les balises entre {% templatetag openvariable %} {% templatetag closevariable %} et {% templatetag openblock %} {% templatetag closeblock %}.
  3. Cliquer sur Reprendre depuis Google Docs : l'application vérifie les balises, fait un remplissage d'essai, puis met le modèle en service. Ouvrir le document d'essai pour contrôler la mise en page.

Le modèle ne contient que le texte type, sans donnée personnelle. Si le partage par lien n'est pas proposé, un administrateur Google Workspace doit autoriser le partage en dehors de l'agence (console d'administration, Drive et Docs > Paramètres de partage).
